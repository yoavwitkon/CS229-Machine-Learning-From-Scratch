# 🎓 Stanford CS229: Machine Learning Implementations

This repository contains my personal implementations of algorithms and concepts learned in Stanford's **CS229 Machine Learning** course. 

The goal of this project is to build core machine learning algorithms entirely from scratch using Python and NumPy, gaining a deep mathematical understanding of how they work under the hood, without relying on "black-box" libraries like Scikit-Learn.

## 📂 Course Contents & Implementations

* **[Lesson 1: Linear Regression & Gradient Descent](./Lesson_1_Linear_Regression)** 
  * Implementation of the Normal Equation.
  * Batch Gradient Descent.
  * Feature Scaling and Model Evaluation ($R^2$, RMSE).

*(More implementations will be added as I progress through the course).*
